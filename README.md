# NTE Bond Gift Explorer

A single-page tool for browsing and comparing character gifts in a bond/affection system. Built as a static HTML file — no build step, no backend, no dependencies.

## What it does

- Lists gifts alongside the character they're for, the affection points they grant, and their price.
- Sort by affection (highest first), by price, by character name, or by an **affection-per-cost ratio** to find the most efficient gifts to buy.
- Filter by character, search by gift name, and toggle between all gifts vs. only gifts that are purchasable with in-game currency.
- Shows live summary stats (best-ratio gift, highest-affection gift) that update as filters change.

## Usage

Open `index.html` in any modern browser. That's it — everything runs client-side.
